# Manual do Vault

## Estrutura
- 00-Inbox/ -> captura rápida, sem organizar na hora
- 01-Projects/ -> projetos ativos, um subdir pro projeto
- 03-Resources/atoms/ -> conceitos únicos, tag #atom
- 03-Resources/molecules/ -> combinações de atoms, tag #molecule

## Convenções
- Filenames: kebab-case descritivo
- Frontmatter obrigatório: tags, date, status
- Links entre notas: [[Nome da Nota]]
