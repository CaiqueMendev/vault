# DeltaHub

## Resumo
CRM de WhatsApp para PMEs brasileiras. Começou como CRM imobiliário e depois pivotou.

## Stack
- FastAPI + Next.js + PostgreSQL, multi-tenant, pipeline Kanban.
- Evolution API self-hosted.
- OpenAI Assistants API: um assistente por workspace, uma thread por lead.
