Sistema de gestão de projetos de habitação social, feito para o pai do Kaká: beneficiários, membros da família e unidades habitacionais.

## Stack
Next.js 16, React 19, TypeScript, PostgreSQL, Prisma 7, NextAuth 5, shadcn/ui, TailwindCSS 4.

- Versão inicial construída.
